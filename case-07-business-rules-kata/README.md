# Case 07 - Business rules kata

Dette caset trener på å kode og teste forretningsregler med tydelige tradeoffs.

## Hvordan kjøre

```bash
mvn test
mvn spring-boot:run
```

## Oppgave

Start i `InvoiceScoring.kt` og utvid regellogikken. Målet er å gjøre koden lett å lese, lett å teste og enkel å endre.

Forslag til øving:
- Legg til støtte for flere rabattkoder.
- Avklar hvordan rabatt skal kombineres med VIP-regler.
- Legg til validering og tester for edge cases.

## Viktig

Dette prosjektet er med vilje lite og uferdig slik at du kan trene på designvalg under tidspress.
