# Case 18 - Feature flag RBAC

## Domene
Plattform / feature flags

## Tid
45-60 minutter

## Hva dette trener
- Access policy
- SRP
- DIP

## Oppgave
Implementer skeleton-koden i `src/main/kotlin` og få testene grønne uten å overdesigne.

- Koden er lett å forklare høyt i intervju.

## Kommandoer

mvn -pl case-18-feature-flag-rbac test
